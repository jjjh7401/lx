Chapter 26

MAtricks and Recipes

One phaser in many shapes

In this chapter
  • With MAtricks Block, Group and Wings, line up the same 8 fixtures again in pairs, as odd/even, or from the outside in.
  • Calculate the phase interval as 360 ÷ the number of splits, and tell apart where the last phase must be entered as 315 rather than 360 and where it need not be.
  • Use recipes and Cook so that cues follow even after you fix a group or a preset.
Opening scene

Say you cut a pizza into eight slices. Read as a clock, the cuts start at 12 o’clock and turn 45° each time: half past one, three o’clock, half past four. The eighth cut is at half past ten, 315° in degrees. Go on to 360° for a ninth and you are back at 12 o’clock, the place of the first cut. On a circle 360° and 0° are the same spot.

The phase of a light is also an angle on a circle. In Chapter 25 we said that giving each fixture an offset phase makes a wave. What happens if you divide this phase literally from 0° to 360° over 8 fixtures? The first fixture gets 0° and the last gets 360°. Like the pizza’s ninth cut, that is the same place as the first. So in a chase where eight fixtures should light one after another, the first and the last light together.

This chapter covers MAtricks, which reorders the same fixtures to use one phaser in many shapes, and recipes, which store that order and those values inside the cue as “how to make it.” Along the way we also see where this 315° trap comes from.

26.1 MAtricks: Changing Selection Order and Grouping

MAtricks gives no values to fixtures. It changes only in what order, and how many at a time, the selected fixtures are placed on the grid. The same phaser then spreads out in a different shape.

The MAtricks window is divided into the three axes X, Y and Z, and each axis takes the following values.1

  • BlockBundles the given number of fixtures and treats them as one. Give 10 fixtures Block 2 and the grid has five cells.2
  • GroupDivides alternately into the given number of groups. Number 1 goes to group 1, number 2 to group 2, and number 3 goes into group 1 again.3
  • WingsDivides into the given number of wings, and each wing picks fixtures from the opposite side. Give 10 fixtures Wings 2 and both ends light together, and each press of Next moves toward the middle.4
  • WidthSets how many fixtures go on one line and sends the overflow to a new line on the next axis (Y). Give 10 fixtures Width 3 and you get four lines of three (the last line has one), so a single row of fixtures can be handled like a grid.5
  • ShuffleMixes the order at random. The same Shuffle value with the same quantity always gives the same order.1
  • ShiftPushes the selection sideways within the grid. On the X axis a positive value pushes right; on the Y axis a positive value pushes down.1

With MAtricks you need fewer effect groups (Chapter 24). From one “Spot left → right” group, changing only the MAtricks gives odd/even and outside → in as well. Save the MAtricks you use often in the MAtricks pool and write what they do in the name (for example, “X Group 2 odd/even”).1 The manual does not say whether the two wings divided by Wings get the phase as a mirror image, so check in the 3D view the first time you use it.[Author to confirm]

From 2.5 you can also set a speed master in MAtricks. The master you set takes precedence over the Speed From/To values entered in MAtricks (values that divide the speed differently from the first fixture to the last), so a phaser whose speed is divided by MAtricks can still follow the song’s BPM (Chapter 28).1 13

Words to Know
Interleave
grandMA2 had a MAtricks value called Interleave. In the grandMA3 manual the word appears only when describing how Group “interleaves” fixtures into groups; it is not a separate value.3

26.2 Phase Interval = 360 ÷ Number of Splits

To spread the phase evenly over the fixtures, offset each one by 360 divided by the number of splits. The phase of the last slot is 360 minus that interval.

Table 26-2 Number of splits and phase interval Calculation
Splits Interval Last slot Example
2 180° 180° Odd/even
3 120° 240° Bloom (center, middle, outside)
4 90° 270° 8 fixtures given Block 2 or Wings 2
6 60° 300° Running, 6 splits
8 45° 315° 8 moving spots
16 22.5° 337.5° 16 moving beams

The number of splits is not the fixture quantity but the number of cells in the grid. 8 fixtures given Block 2 make four cells, so it is 4 splits. Fixtures that share a cell get the same phase.6 [Author to confirm]

One number

The last phase for 8 fixtures is 315, not 360 (Calculation: 360 − 360 ÷ 8). However, some ways of entering it have the console do this calculation for you, so whether you must enter 315 yourself depends on where you enter it.

For a 1-in-N chase (a chase in which only one fixture is on at a time as it passes), match the Width too. The on-step Width is 100 ÷ N, the off-step is the remainder, and the phase runs from 0 to 360 − 360 ÷ N. For 8 fixtures that is on 12.5, off 87.5, phase 0–315.6

26.3 Where to Enter 360 and Where to Enter 315

Spread the phase evenly over 8 fixtures and the last fixture gets 315°. But the console has both places that adjust to 315 by themselves when you enter 0–360, and places that use the value literally.

In the former, enter 360; in the latter, enter 315 yourself as the last value. Mix the two and the first and last fixtures light together, or conversely the spacing narrows.

The manual’s Quick Start Guide says that pressing the calculator’s “0 thru 360” button spreads the fixtures evenly over the whole loop, and explains why: if the console literally divided 0 to 360, the first and last fixtures would be doing the same thing.7 So with this button the console changes the last phase to 315 by itself (for 8 fixtures). On the other hand, an MA administrator on the MA Lighting forum answered that the 0 thru 360 in the MAtricks window really is 0 to 360, so the first and last fixtures move identically.8

The command-line At Phase 0 Thru 360 means “put into the phase (Phase) of the selected fixtures, divided in the order picked, from 0 for the first fixture to 360 for the last (At).” At Phase Percent 0 Thru 360 is the same with Percent added. For the command line the sources disagree. An older forum answer (version 1.6) said only the form with Percent, At Phase Percent 0 Thru 360, spreads automatically, while the author’s 2.4.2 notes record that At Phase 0 Thru 360 produced a wave. But those notes confirmed only that a wave appeared; they did not look at whether the first and last fixtures coincide.9 For places like this, enter it yourself and check, as in the exercise of Section 26.6.

One more thing: there are reports that when the fixture quantity changes, the phase in MAtricks and recipes is not recalculated. The 315 entered for 8 fixtures stays 315 when you move to a 9-fixture stage.8 On a tour where the quantity changes with each venue (Chapter 18), keep a list of the places where you entered phase literally and fix them for each venue.

26.4 Reversing the Wave Direction

The direction of a wave is set by the order picked, not by coordinates. This is where what we said in Chapter 24, that a group stores the order, gets used.

A group stores the selection and order of fixtures, and the manual says this order and the grid are essential when you enter range values or build a phaser.6 So to reverse a wave that runs from left to right as seen from the audience, there are two ways.

  • Use a group picked in reverseMake a separate “Spot right → left” group. The author confirmed on onPC that giving the selection order in reverse made the wave run in reverse too.9
  • Spread the phase in reverseEnter 0 thru −360 (divide in the opposite direction, from 0 for the first fixture to −360 for the last). It remains in the author’s 2.4.2 notes as syntax the console accepted.9

There is also a forum answer from MA staff that MAtricks’ InvertX (flipping the X axis) reverses the phaser’s direction of travel and range of values, and is not a tool for reversing the order picked.[Author to confirm] When you change direction, using one of the two methods above makes the result easier to predict.

26.5 Recipes and Cook

A recipe does not put values directly into a cue; it stores “how to make it”: which group, which preset, with which MAtricks. So when you fix a group or a preset and Cook again (recalculate the values from how to make them), the cue follows the fix.

A recipe is attached not to a cue but to a cue part (a cue split by group of fixtures, used when you give different groups different timing). To edit a recipe you must turn on the Show Recipes mask of the Sequence Sheet (a display setting that shows the recipe lines). A recipe line holds the selection (group), the value (preset), MAtricks, a filter, and fade, delay, speed, phase and so on.10 Calculating real values from this how-to and putting them in the cue is called Cook.

If the same cue part has both a value and a recipe, which goes out? The order the manual sets is: the cue part’s value, the cue part’s recipe, the preset’s value, the preset’s recipe. If an earlier one exists, it goes out and the later ones are not used. So if you have put a value directly into a cue part, that value goes out ahead of a recipe for the same attribute.11

You read the state of a recipe by the color of the Cook icon.

Table 26-4 Colors of the recipe Cook icon 11
Color Meaning
Green All ordinary recipe lines are cooked
Purple All phaser recipe lines are cooked
Red One or more failed
Orange Cooked and uncooked values are mixed

When should you Cook? When you edit a recipe line the console cooks automatically (MergeLowPriority mode: it changes cooked values and adds new ones, but does not touch uncooked values).10 But if you have changed the contents of the group or preset the recipe points to, you must Cook that sequence again for the cue to reflect it.[Author to confirm] The command is written like Cook Sequence 11 (recook all the recipes of sequence 11). In this book’s numbering rules, 11 is the scene sequence of song 1 (LOVE ATTACK) (Table 29-2 in Chapter 29). If you add no option, a window opens to choose the Cook mode.12

In 2.5 the ways of making and editing recipes changed a great deal.13

  • Making a phaser recipe directlyTurn on Edit Recipe mode, press a group in the group pool, then press a preset in the position pool. Press Next Step on the encoder bar and press another position preset, and you have a two-step phaser recipe.
  • Names of recipe linesPhaser recipe lines are named by selection and shape, ordinary recipe lines by selection and value. Just reading the line name in the Sequence Sheet tells you what the line does.
  • Speed Master columnEach recipe line has a new column for setting the speed master (Chapter 28).
  • Recook buttonThere is a new button that recooks a recipe line. Use it after editing a phaser recipe or a recipe that holds timing values.
  • Link Steps, Make Other SymmetricalWith Link Steps set to Yes, the paired values in a shape change together, and Make Other Symmetrical makes the other step’s Transition symmetrical. It saves effort when you keep two steps in the same shape, like the sine in Chapter 25.
  • Turn into Phaser RecipeIn the editor of a Universal phaser preset you can turn that phaser into a phaser recipe. It is a feature to try when you want to spread again over a group a phaser that was stored as Universal and so became the same phase on every fixture (Chapter 24).[Author to confirm]
  • Cook with a world selectedIf you Cook the programmer’s recipe with a world (a filter that narrows the range of usable fixtures and attributes) selected, only the fixtures and attributes in that world are cooked.

In 2.5.0 there was a problem where the length of a cue holding a recipe was calculated wrongly, and it was fixed in 2.5.1.0.14 For a show that uses many recipes, get the bug-fix release.

Recipes are not always better. On a show whose fixture setup changes often, like the tour of Chapter 18, recipes fit because after fixing groups and presets, Cook alone makes the cues follow. Conversely, values unique to each fixture, such as positions, or a look used once, are simpler stored as values.[Author to confirm]

26.6 [Exercise] Enter the Phase of an 8-Fixture Chase Five Ways

Put a 1-in-8 dimmer chase on 8 moving spots, enter the phase five ways, and see for yourself whether the first and last fixtures coincide. This exercise is also the work of filling in the blank cells of Table 26-3 on the console version you are using.

Follow along

  1. Select the “Spot left → right” group (301–308) from Chapter 24 and make a two-step dimmer phaser. Step 1 100% (Width 12.5), step 2 0% (Width 87.5), Transition 0 on both, Measure 4.
  2. Enter the phase one way at a time from the five below and look at the 3D view each time. ① The calculator’s “0 thru 360” button ② The command line At Phase 0 Thru 360 ③ The command line At Phase Percent 0 Thru 360 ④ Phase From 0, To 360 in the MAtricks window ⑤ Phase From 0, To 315 in the MAtricks window.
  3. Compare the five results without storing. On 2.5, make the same chase also as a phaser recipe in Edit Recipe mode and try 0–360 and 0–315 in the phase field.
  4. Next, change MAtricks to Group 2, Wings 2 and Block 2 in turn and see whether the shapes of Figure 26-1 come out.
  5. For LOVE ATTACK’s upper moving (Table 25-4 in Chapter 25), enter the phase by the method that fits and store it in an All pool with /Selective.
How to check
  1. For each of the five results, see whether fixtures 301 and 308 light at the same moment.
  2. If they light together, that method calculated literally, so you must enter 315 as the last phase.
  3. If over one cycle the eight fixtures light once each at an even spacing, that method had the console spread it evenly.
  4. Write the results in the blank cells of Table 26-3.
Try it with your own stage
  1. In the show you are working on, pick three groups of different quantities (say 6, 8 and 12 fixtures) and calculate the interval and last phase with Table 26-2.
  2. If anywhere in the show file you entered phase literally, write that list down separately.
  3. When the fixture quantity changes, fix that list first.

Key points

  • MAtricks changes not values but the order and grouping of fixtures. Block bundles, Group divides alternately, and Wings picks from both sides.
  • The phase interval is 360 ÷ the number of splits, and the last slot is 360 − the interval. The number of splits is the number of cells in the grid, not the quantity.
  • The calculator’s “0 thru 360” button and the Phaser Editor’s 360 button have the console spread it evenly. The MAtricks window and recipes calculate literally, so for 8 fixtures enter 315.
  • The direction of a wave is set by the order picked.
  • A recipe stores how to make it. If you have fixed the group or preset it points to, Cook.
  • On 2.5, make phaser recipes directly in Edit Recipe mode, and set a speed master for each recipe line.
On the job tomorrow
  1. When you apply a wave effect, look at only the first and last fixtures separately in the 3D view.
  2. If the two light together, think of the last phase, 315.
