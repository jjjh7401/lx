Setlist Arc

The board for seeing the flow of one whole concert (Chapter 18). List the songs in order and, for each song, enter energy, main color, main role, how it is run and the special it reveals, and it draws the energy arc and color band of the whole show. It points out where peaks are crowded, where neighboring songs share a color and main, and specials that come out too early. Write VCRs and talk between songs in the type column too so they join the order, and mark where a block (a costume change and so on) starts. An awards show run sheet (Chapter 19) is built the same way. A stage where each act does only one or two songs, like a music show, suits the per-song tool (the Song Workbench) instead.

Items

The type column is free text. Leave it empty or start it with “song” or “performance” and the item counts as a song and gets a dot on the arc. If it contains “award” it is drawn as a white cell, if it contains “MC” or “host” as a blue cell, and anything else as a dark cell in the band.
