A board for the Chapter 9 exercise. For each section of the Song Map, write a look name, one main role, a position (position preset), an effect and an in time. The two colors are shown exactly as you picked them in the Palette (Web tool 8).

Main flow

When the same color runs for more than three cells in a row, the whole song reads as one picture. Key is exempt from the main rule, so a section where the key is the main is one where the song is the center.
