Music Map Practice

Web tool 4 · Chapters 3–4

Enter the BPM and the first downbeat, then write sections and changes by bar. It calculates the times, draws a music map, and builds the song map text. It starts with the example of the practice song LOVE ATTACK. Edit the table and the map changes right away.

Section

Write only the start bar and the end bar is calculated up to just before the next section. Energy is 1–5 (Chapter 4).

Changes

Beats run 1–4. A hit that comes in one beat early is written as beat 4 of the previous bar.
