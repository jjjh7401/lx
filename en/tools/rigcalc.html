Rig Calculator and Patch Sheet

Enter the fixture list and it calculates weight, power and universes; set the numbers, addresses and positions and it builds the patch sheet, the universe map and the plan and elevation for you to check. Use it for the Chapter 22 exercise and for your own stage on site. What you write is saved in this browser.

Import · Export — spreadsheet, Vectorworks, Fixture Roles, backup

Copy a table exported from a spreadsheet or Vectorworks, including the first row (the column names), and paste it in. It recognizes column names such as Instrument Type, Position, Purpose, Channel, Universe, DMX Address, Footprint, Weight and Wattage (also Fixture, Role, Qty, Mounting, ID, X, Y, Z). An address may be written 2.301 or 2/301, and when there is no universe column an address counted straight through, like 813, is split for you. Pasting this tool’s own backup (“Copy backup” below) restores it exactly.

Write one row per type and position. Even for the same model, split the row if it hangs in a different position (back truss wash, middle truss wash). Channels is the channel count of the mode you will use; copy weight and power per unit from the manufacturer’s spec sheet.

Quantity by role

To check

    For each row, enter a starting ID and a universe, then press Fill addresses and the start addresses are filled in. A row of the same type as the one before it in the same universe is chained on; when the type changes, it starts at the next hundred address (101, 201…). Leave the universe empty and the fixture is treated as off the console (follow spots and so on).

    Universe map

    One bar is one universe of 512 channels. Color is the role of the fixture that uses the channels, gray is channels left empty, and a red dotted outline is a fixture that goes past 512. Hover over a bar to see the fixture and its address.

    For each row, enter X (left–right) · Y (front–back) · Z (height) in meters. The origin is the center of the front edge of the stage, +X is stage left (the right side as seen from the audience), and +Y is upstage. The fixtures in one row are spread evenly between start and end. For a tower stacked vertically, keep X the same and enter Z as start–end.

    The patch sheet, spread out fixture by fixture. After checking the five points, copy it into a spreadsheet or send it to the rigging, electrical and systems crews.

      Patch sheet

      Calculates the diameter one fixture lights, and the quantity needed to cover a width evenly. Use it when deciding the quantity of key and wash. The quantity of the beam role is set by the shape you want to draw, not by the width it covers.

      Beam diameter = 2 × distance × tan(beam angle ÷ 2). Quantity = ((width − diameter) ÷ spacing, rounded up) + 1 (the fixtures at both ends sit half a diameter inside the stage edge). Use the beam angle, not the field angle on the spec sheet. The two overlap standards are in Section 22.4. A model with soft edges can overlap less, so on site hang one first and decide.
