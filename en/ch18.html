Chapter 18

Concerts and Tours

Shaping the flow of a whole show

In this chapter
  • Place the staging of one song inside the flow of the whole set list (the energy arc).
  • Decide when to reveal each show special (show it for the first time), and avoid repetition between songs.
  • Choose how to run the show (by hand, timecode or hybrid) and how to trim the rig to the size of each tour venue.
Opening scene

Think of the first song of a concert. The curtain rises, every beam shoots into the sky at once, lasers cut across the audience, strobes burst. The crowd answers with a roar. But about ten songs later, strangely, it all feels flat. The beams and lasers are things you have already seen. And there are still more than ten songs to go.

The first song did nothing wrong. Taken alone, it is excellent staging. The problem is that it forgot it was the first song of the whole show. Through Part 3 we left headroom inside one song; at a concert you do the same thing across the whole set list.

18.1 The Energy Flow of the Whole Set List

Concert lighting starts not from one song but from the energy flow of the whole set list. On site this flow is called the arc.

As in Chapter 4, where you gave each section of a song an energy level, at a concert you give each song an energy level and draw a line across the set list. This line is the large structure of the show.

Drawing the arc shows you three things.

  • BlocksA set list is usually divided into blocks of three or four songs. The points where costumes change or the stage position moves, and where a video (VCR) plays, are the block boundaries. If you fix a color and a signature fixture for each block, the blocks separate clearly from one another.
  • Breather songsThere must be low-energy songs in the middle so that the big song of the next block looks big. The dark cue inside one song (Chapter 10) becomes a breather song inside a show.
  • The peakA show has one peak. It is usually the last song of the main show or one song of the encore. Saving things for that song is the show special of Section 18.2.

The brightness plan of one song (Chapter 10) and the arc of a show are read the same way. As you saved 100% for Chorus 3 inside a song, inside a show you save the whole rig for the peak song.

18.2 The Song Where the Show Special First Comes Out

A show special that you save, such as lasers or a hidden rig, has the song where it is first shown decided in advance. Showing something for the first time is called a reveal on site.

Lasers, kinetics (moving trusses or lights), a hidden line of fixtures, and a scene that lights the whole audience are show specials. It is the special cue of Chapter 10 widened to the whole show.

Table 18-1 The order for bringing out show specials Starting value 1
Place in the show What comes out What is saved
First song The basic rig (wash, beam, key). One signature look that becomes the first impression of the show Lasers, kinetics, the whole audience, heavy strobe use
End of the first block Reveal one special The remaining specials
Middle blocks One new special per block, or a new use of one already revealed The combination for the peak
Last song of the main show All the specials so far, together One for the encore (if there is one)
Encore The one you saved, or a scene shared with the audience —

The point is to decide one song to reveal each special. If you don’t, “let’s use it in this song too” comes up again and again at rehearsal, and in the end every piece of equipment is shown in the first block.

18.3 Repetition Between Songs

The same lighting coming back inside one song is a strength, but similar lighting in neighboring songs is a weakness (Chapter 14). If the signature looks of the previous and next songs have the same color and the same position, the audience remembers the two songs as one.

So when building a set list for a concert, write each song’s signature look (Chapter 9) and main color (Chapter 8) on one line. If two neighboring songs have the same main color, change one, or change the main role even if the color stays (beams in one song, wash in the next). If you continue the color inside a block and change it between blocks, the blocks separate by color.

A short experiment
  1. Find the set list of a concert by an artist you like, and write one word for the color you remember from each song.
  2. If there is a run of songs you can’t remember, those songs were probably similar pictures on stage.

18.4 How to Run the Show — By Hand, Timecode, Hybrid

At a concert you keep one cue list per song, and depending on the character of the song you decide whether to press GO by hand or to hand over automatically to timecode (Chapter 16). There are three ways.

Table 18-2 How a concert is run Starting value 1
Method Songs it suits What to watch for
By hand (GO button) Songs a live band plays, songs whose tempo differs a little each time, talk A hit that lands one beat after a dark cue is easy for the hand to miss
Timecode Songs on a backing track (MR), songs that must match the video exactly, songs with dense cues If the MR version changes, every cue slips. Check the audio version last (concept meeting, Chapter 7)
Hybrid Most concerts Section changes and video sync on timecode; accents such as strobes and blinders by hand

When a band plays live, the BPM of a song differs a little from show to show. In that case, tie the effect cycle (Chapter 12) to the console’s speed master (Chapter 2) and set that day’s speed with tap tempo. Then you press the cues by hand and only the speed of the effects follows that day’s tempo. The console side is covered in Part 5.

18.5 Tours — Trimming to the Size of the Venue

If you travel to venues of different sizes with the same show, build trimmed versions of the rig in advance. Dividing into three sizes — club, mid-size venue and arena — is the starting point.2

The principle in trimming is keep the role, cut the quantity. It is fine for a role that had 32 beams in a big venue to have 8 in a small one, but if the role of beam itself disappears, you must change every cue that depended on that role.

Even on the trimmed version you keep using the same cue structure. For that, the console’s groups (Section 22.6, Chapter 24) must be divided by role, not by fixture number. If the “beam group” points to 32 fixtures in an arena and 8 in a club, then the “beam group fan position” in a cue can be used as it is in both places. But truss height and stage width differ from venue to venue, so position presets and pixel maps are readjusted for each venue. We look at this again in Chapter 22 when building the rig.

18.6 Between Songs and the Encore

The few seconds from the end of one song to the start of the next set the flow of the show.

The transition cues of Chapter 14 (clearing, leaving light, preparing the next song) are used here every time. At a concert there are two more things to think about.

  • Time for applauseWhile the artist bows or talks after a song, light the stage with the key and a weak base. If the talk runs long, you can raise the house lights (the lights over the audience) a little so that the audience’s faces can also be seen.
  • Waiting for the encoreAfter the main show ends, the time spent waiting for the encore is when the audience fills the stage. While light sticks and phone lights fill the seats, keep the stage lighting to a minimum and prepare the first look of the first encore song as an MIB (Chapter 14).

18.7 [Exercise] The Whole Set List on One Table

Write energy, main color and signature fixtures on one line for each song, and look at the whole set list on one sheet. When it is all written down, the energy flow shows as a line, and you can see where neighboring songs overlap and which special came out too early.

Follow along

  1. Write the songs of the set list in order, and write the BPM and energy (1–5) for each song. Take a song’s energy from the energy of its biggest section.
  2. Draw block boundaries where costume changes, VCRs and talk come in.
  3. Write the main color, signature look and main role for each song.
  4. Decide one song to reveal each show special (laser, kinetics and so on).
  5. Write the way of running each song (by hand, timecode, hybrid).
How to check
  1. On the energy line, see whether there is a single peak, and whether the first block has already reached it.
  2. Mark the places where two neighboring songs have the same main color and the same main role, and the places where two or more specials are revealed in the first block, and write the reason.

Put LOVE ATTACK in as one song of a set list and you can read it like this. 112 BPM, energy 5, main color pearl pink, main role beam (chorus). It is a pastel song, so placed between strong primary-color songs it becomes a breather color, and placed next to another pastel song the two look like one. Where to place it is decided by what role the “scent” of the concept sheet (Chapter 7) plays inside the block.[Author to confirm]

Try it with your own song
  1. Make the same table with the set list of the show you are working on now.
  2. If a reveal spot changed during rehearsal, write it next to the first plan and, after the show, compare which one was better.

Key points

  • Concert staging starts from the energy arc of the whole set list. Decide the blocks, the breather songs and a single peak.
  • For show specials, decide one song to reveal each. Do not show everything in the first song.
  • Repetition inside a song is a strength; repetition between songs is a weakness. For neighboring songs, change either the main color or the main role.
  • Choose how to run each song from by hand, timecode and hybrid. With a live band, tie the effect cycle to the speed master.
  • On a tour, keep the role and cut the quantity. If groups are built by role, the cue structure stays as it is, and position presets and pixel maps are readjusted for each venue.
