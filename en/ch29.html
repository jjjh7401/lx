Chapter 29

Show File Templates

Build once, use again

In this chapter
  • Decide what to fix and what to leave empty in a template, for sites where the songs change every week and for sites that do the same show every day.
  • Give groups, presets, sequences and pages number ranges, so that whichever show file you open you find the same thing in the same place.
  • Know the order for moving a template to a different rig, and tell what must be rebuilt from what can be used as it is.
Opening scene

Say two people write a weekly report every Monday. One opens a blank document every week and rebuilds the title, the tables and the items from scratch. The other keeps last week’s report as a form and changes only the numbers and this week’s content. The second person spends no time building the frame of the report, so uses that time to look over the content once more.

The same thing happens every week on a lighting console. For TV music shows the songs change every week, and sometimes the stage design changes from broadcast to broadcast. Even so, much is built the same way every time: how groups are divided, the basic palette, the place of the safety button. If you build the show file new every time, you pick the same kind of groups again, match the same colors again, and put down the same safety button again.

This chapter covers how to turn the LOVE ATTACK show file built in Chapters 23–28 into a template. A template is a show file in which everything else is decided in advance, so that for the next song or the next show you only fill in “what belongs to the song.”

29.1 Two Kinds of Templates

What to decide in advance in a template depends on the site. If the songs change every week, fix the presets and groups and leave the songs empty. If you do the same show every day, fix the songs and adjust the presets and groups to the rig.

Table 29-1 Two kinds of templates Starting value
Songs change every week (TV music shows, Ch. 17) The same show every day (tours Ch. 18, light shows Ch. 20)
Fixed How groups are divided and numbered, the basic palette, the phaser sets, the song-page layout, safety Song pages and cues, timecode, the song’s palette
Left empty The cues on a song page, the song’s special colors, timecode —
Changed for each performance A new song page for each song. If the stage design changes: the patch, the groups’ selection grids, positions The venue’s fixture counts, positions, pixel map
Features used a lot Preset references (Ch. 23), the same page layout (Ch. 27) Recipes and Cook (Ch. 26), Clone (Section 29.4)

Think of a week of a TV music show (Chapter 17): the time to prepare each song is tight. If on top of that you pick groups and set positions, there is no time to read the song. If the template already holds everything from the groups’ frame to the phaser sets, then even in a week when the stage design changes, you only fit the patch, the group grids and the positions to the new stage (Section 29.4). What you do per song shrinks to moving the cue sheet onto the song page.

A tour is the opposite. The show is the same and the venue changes. As we saw in Chapter 18, even when the fixtures decrease or increase from venue to venue, the cue structure is used as it is if the group names and levels are the same. The template holds the cues, and at each venue you adjust the groups and positions.

29.2 Setting the Pool Number Rules

Divide the template’s pools (the lists in which groups, presets and sequences sit by number) by number range. Put what is used across the whole show at the front numbers, and what is used only in a song in the number range decided for each song.

Then whichever show file you open, you find things in the same place: “Pearl Pink is in song 1’s color range,” “the downlight is common position 1.”

grandMA3 has a basic setting that helps with this. For each pool you can set the First Index (the number a newly stored object starts from; default 1, 1–9999).1 If you change the Color pool’s First Index to 201 when making song 2’s colors, newly stored colors go in from number 201.

Table 29-2 The template’s number ranges Starting value
Pool Whole show Per song
Group 1–10 all groups, 11–30 sub groups, 31–60 effect groups (Ch. 24) Not used (groups are shared by the whole show)
Dimmer 1–10 brightness steps (0, 25, 50, 75, 100) Not used (brightness steps are shared by the whole show; a brightness used only in a song goes into the cue as a hard value)
Color 1–20 white, CTO, basic colors Song n starts at n × 100 + 1 for 20 slots (song 1 is 101–120)
Position 1–30 downlight, wall, fan, cross, sky beams, audience Song n starts at n × 100 + 1 for 10 slots
All (phaser) 1–30 dimmer phaser sets (Table 25-3 in Ch. 25), 31–60 moving phasers Song n starts at n × 100 + 1 for 20 slots
Sequence 1–10 key, safety, house light (Auto Fix in slots 9 and 10 of every song page) Song n starts at n × 10 + 1 for 8 sequences (in the order of slots 1–8 in Table 27-1 of Ch. 27; song 1 is 11–18)
Executor page Page 1 safety and busking (Ch. 21) Song n is page n + 1

The numbers themselves have no right answer. The manual does not set pool numbers, and even in the author’s show the preset pool numbers (All 1 = number 21 and so on) could differ from show to show.2 What matters is to write the numbers you chose inside the template. If you leave the number-range table on the show file’s first page or in the names of pool objects, then even when someone else opens that show file, they work by the same rules.

Some show file templates use big numbers of their own, such as putting a song’s sequences from number 9001. Those numbers are that template’s rule, not grandMA3’s default.3 When you take over someone else’s template, read that template’s number-range table first.

After reading the number-range table, you still have to find where an object actually is. The Locate command that arrived in 2.5 does this. Write Locate Group "Spot left → right" and that object flashes red in the pool, and if it is attached to an executor, that executor flashes too. Type the same command again and it shows, in turn, the pages the object is attached to. You can also search by page and executor, as in Locate Page 2 Executor 201 (executor 201 on page 2, the first fader slot of song 1’s page). To finish, use Locate Reset or ESC.7

29.3 The Song-Page Template and Safety

In the template, a song page holds only the cue numbers and names, with the content left empty. Lay down the cue-number rule of Chapter 16 and the executor slots of Chapter 27 in advance, and a new song only has to fill in the slots.

Table 29-3 The song-page template Starting value
Cue Name What is put in the template in advance
0.5 Blocking Dimmer 0 on every fixture, movers at the common position, all layers off
1 Intro Empty
10, 20, 30 … Start of a section (verse, pre-chorus, chorus …) Empty (number and name only)
29, 59, 79 Dark cue and break Base only, dimmer 0, MIB Early
39, 69 Kick-out Empty (number and name only), MIB Early
90 End Empty
99 Finish Front light for the bow

The blocking cue (0.5) is the most important cue in the template. It is a cue stored with a value for every attribute, so whatever came through tracking from the previous song, passing this cue starts the song from the same state. grandMA3 has no feature named a “safety cue,” but a few basic functions used together do the same job.4

  • Restart Mode = First Cue When you turn the sequence on again, it starts from the first cue (0.5).
  • Release First Cue Releases the values tracked in the first cue.
  • Wrap Around Press GO after the last cue and it returns to the first cue. This is handy when you run the same song several times in rehearsal.

Put the safety buttons not on a song page but on page 1 and the Auto Fix executors (the safety row in Chapter 21, slot 10 in Table 27-1 of Chapter 27). This is so that, whichever song page is up, the hand finds the safety look, the dark cue and the blackout in the same place.

29.4 Moving to a Different Rig

When the venue or stage changes and the rig is different, fix the template in the order patch → the groups’ selection grids → positions → check. If you delete the whole patch and put in a new one, the groups and presets lose their fixtures and there is no point in using a template.

Table 29-4 The order for moving a template 5 6
Order What to do What to look at
1 Patch Do not delete fixtures; if the count is the same, change only the fixture type, and if it grows, copy the data with Clone After changing the fixture type, whether the presets and cues are still alive [Author to confirm]
2 Direction Set the patch’s pan and tilt invert first (Ch. 24) If positions look flipped, check the invert before the presets
3 Groups Pick the effect groups’ selection grids again to fit the new stage Check the order with Highlight and Next
4 MAtricks · phase Fix the Block value of groups whose count changed and the literally entered phase (Ch. 26) Whether a 315 meant for 8 fixtures is left behind
5 Recipes Cook the sequences whose groups you fixed (Ch. 26) Whether the Cook icon is green or purple
6 Positions Values are unique to each fixture, so aim again at every venue Start with the key position and the audience direction
7 Check Run the song page from start to finish Ch. 30 rehearsal checklist

Clone copies the data of one fixture (or a selection) to other fixtures across the whole show file. The syntax is Clone target At destination. For example, Clone Fixture 301 Thru 308 At Fixture 311 Thru 318 copies the groups, presets and cue data of the 8 spot movers as they are to 8 newly added fixtures.5 The manual says that when you Clone preset and cue data, the presets the destination fixtures refer to are copied too. To narrow the range, add If. Clone Fixture 301 Thru 308 At Fixture 311 Thru 318 If Sequence 11 Thru 18 means copy only the data that is in song 1’s sequences (numbers 11–18).5

The manual does not say how much of the presets and cues survive when you change only the fixture type in the patch. There are accounts from people who build templates, but when the fixture type differs the attribute names differ, so some values may drop out.6 So after changing a fixture type, always go through to step 7 of Table 29-4. And after changing the patch, you must save with Save and Exit for it to take effect. If you press Discard and Exit, the changes are cancelled.6

Know too what is easy and what is hard to move. Color and dimmer recipes move well regardless of the rig, but positions are values unique to each fixture, so you fit them again at every venue. A phase phaser saved as Universal loses its phase when moved (Chapter 24), so keep the template’s phasers Selective.

What changed in 2.5
  • Names used in macros: If the template has macros (several lines of commands in one button), see whether they use command options whose names changed in 2.5. The option that moves to the next line in the selection grid (Newline → New Line), the option that restarts timecode from the beginning (Restart Option → Toggle Restart Option) and the range when exporting a patch (Entire Patch → All Stages) have changed, and a macro that tidies recipes now writes Recipe after /Type instead of CleanUp /Selective.8
  • The place of Shapes: The Shapes pool that holds phaser shapes moved from slot 16 to slot 4 in the show data. Fix any macro that goes to this slot by number.8
  • Remote control: In OSC, which other programs use to send commands to the console, the symbol that separates commands changed to a semicolon (;), and the default rights of a remotely connected user were set to Presets. If the template is one where you control the console from a tablet or another program, test the connection again.8
  • If the template uses neither macros nor remote control, you may skip the three lines above.
  • Locate: A command was added that finds objects in pools and executors and makes them flash (Section 29.2).7
  • If you open a template made in 2.4 in 2.5, run each of the template’s macros once before checking with Table 29-5.[Author to confirm]

29.5 The Template Checklist

Before you hand a template to someone else or open it at the next show, check the ten items below.

Table 29-5 Template checklist Starting value
What to look at Related chapter
1 Are the patch’s ID range and the number-range table written inside the show file? 24
2 Does each effect group’s selection order match the stage? 24·26
3 Is the preset mode of every preset in the preset pools Selective? 24
4 Are the fixed presets filled in up to the show’s maximum number of steps? 27
5 Do all phasers follow the same speed master? 28
6 Is there a list of the literally entered phases and Block values? 26
7 Does the blocking cue of the song-page template hold every attribute? 29
8 Are the key and safety on every page as Auto Fix? 27
9 Are song-only things (special colors, the song’s timecode) kept from mixing into the common number range? 29
10 Does the show file go to black as soon as it opens (no output left from the previous show)? 23

29.6 [Exercise] Make a Template from the LOVE ATTACK Show File

Strip what belongs to the song out of the show file built in Chapters 23–28, save it as a template, and use that template to make the empty song page for a second song.

Follow along

  1. Save the show file under another name (for example “Template_PracticeRig_v1”).
  2. Move the presets to fit the number ranges of Table 29-2. LOVE ATTACK’s Pearl Pink, lilac, aqua and red go to song 1’s number range (101–), and white and the basic positions stay in the common number range.
  3. Copy the LOVE ATTACK song page to make the song 2 page, then erase the content of the cues so that only the Table 29-3 template remains. Keep the blocking cue (0.5), the dark cues and break (base-only state) and the finish cue (99).
  4. Give the scene sequence Restart Mode = First Cue, and check that the key and safety are on every page as Auto Fix.
  5. On the show file’s first page, write the number-range table of Table 29-2.
  6. Check with Table 29-5, then save it as a template.
How to check
  1. Open the template fresh and, within 15 minutes, try making the first three cues of a different song (the start of the intro and the verse) on the song 2 page.
  2. If you spent time picking groups or fitting positions, that is what the template is missing.
  3. Add it to the template.
Try it with your own stage
  1. Open the show file of the show you are in charge of now and check it with the ten items of Table 29-5.
  2. After fixing what gets caught, save it as a template with the date and version in its name, and at the next show start from that template.

Key points

  • At a site where the songs change every week, fix the presets and groups and leave the songs empty; for the same show every day, fix the songs and adjust the presets and groups to the rig.
  • Divide the pools by number range, and write that number-range table inside the show file. First Index sets the starting number of a number range.
  • Keep the song page as a template with only numbers, and the blocking cue (0.5) cuts the previous song’s tracking.
  • When moving to a different rig, do not delete the patch; fix in the order patch → direction → group grid → phase → Cook → positions → check.
  • Before handing over a template, go through the ten-item checklist.
On the job tomorrow
  1. Write down what you rebuilt from scratch this week.
  2. If anything was rebuilt two or more times, move it into the template.
Closing Part 5

In Part 5 we moved what Parts 1–4 decided in words and tables onto the grandMA3 console. We learned the path data takes inside the console (Chapter 23) and moved the rig into the patch, groups and presets (Chapter 24). We built rhythm layers from the phaser’s five parameters (Chapter 25) and spread the same phaser into many shapes with MAtricks (Chapter 26). We programmed a song with a song page (Chapter 27), matched it to the BPM and then recorded it with timecode (Chapter 28). Finally we kept all of that as a template (Chapter 29).

The console has many features, but these chapters used only a few principles. Make the presets first. The order you picked is the direction. Store in Selective. Tie the speed to the song’s one BPM. Where something must stop, stop it down to the step. In Part 6 we run rehearsal and the show with the cues made this way. We start with how to check and fix cues in rehearsal.
